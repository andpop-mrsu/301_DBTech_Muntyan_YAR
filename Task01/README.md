# Структура файлов данных

## genres.txt
Содержит список жанров фильмов. Каждый жанр записан в отдельной строке.

## occupation.txt
Содержит список профессий пользователей. Каждая профессия записана в отдельной строке.

## movies.csv
Содержит информацию о фильмах.

Поля:
- `movieId` — идентификатор фильма;
- `title` — название фильма;
- `genres` — жанры фильма.

## ratings.csv
Содержит оценки пользователей фильмам.

Поля:
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `rating` — оценка фильма;
- `timestamp` — время выставления оценки.

## tags.csv
Содержит пользовательские теги для фильмов.

Поля:
- `userId` — идентификатор пользователя;
- `movieId` — идентификатор фильма;
- `tag` — текст пользовательского тега;
- `timestamp` — время добавления тега.

## users.txt
Содержит информацию о пользователях.

Поля:
- `userId` — идентификатор пользователя;
- `name` — имя пользователя;
- `email` — адрес электронной почты;
- `gender` — пол пользователя;
- `birthday` — дата рождения;
- `occupation` — профессия пользователя.

## ratings_count.txt
Содержит две строки:
- минимальный идентификатор пользователя и количество его оценок;
- максимальный идентификатор пользователя и количество его оценок.

## sqlite.txt
Содержит номер установленной версии SQLite и список доступных режимов вывода данных утилиты `sqlite3`.
