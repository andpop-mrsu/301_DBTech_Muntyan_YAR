# Лабораторная работа 2

## Описание

Скрипты выполняют подготовку SQL-скрипта и создание базы данных SQLite
из исходных текстовых файлов.

## Требования к окружению

Для работы необходимы:

- Python 3.x;
- SQLite3.

Проверка Python:

    python --version

Проверка SQLite:

    sqlite3 --version

В данной работе использовались:

- Python 3.13.5;
- SQLite 3.53.4.

## Файлы

- `make_db_init.py` — генерирует SQL-скрипт `db_init.sql`;
- `db_init.sql` — SQL-скрипт создания таблиц и добавления данных;
- `db_init.bat` — запускает генерацию SQL и загрузку данных в SQLite;
- `movies_rating.db` — созданная база данных SQLite;
- `movies.csv` — данные о фильмах;
- `ratings.csv` — оценки пользователей;
- `tags.csv` — пользовательские теги;
- `users.txt` — данные пользователей;
- `genres.txt` — список жанров;
- `occupation.txt` — список профессий.

## Запуск

Запуск выполняется командой:

    db_init.bat

После выполнения создаётся база данных:

    movies_rating.db

В базе содержатся таблицы:

- `movies`;
- `ratings`;
- `tags`;
- `users`.

Время выполнения скрипта на используемом компьютере составило менее 2 секунд.
